# V8 车窗运动预览

> 本文保留初版记录；当前修正版请先阅读 [分窗轨迹、门腔修正和截图](V8-motion-review.md)。

启动：`npm run dev`，访问 http://127.0.0.1:5173/ 。

页面支持鼠标/触摸旋转、缩放、五个预设视角、四窗独立滑块、独立或整体全关/半开/全开，以及 2/5/10 秒单程往返播放。暂停保留当前位置。操作滑块或预设会停止循环；运动中改变目标会从当前位置继续。点击窗洞选择目标，即使玻璃已降下仍可选择。

## 文件

- `src/config/v8-windows.ts`：节点映射、固定三角玻璃名单、逐窗关键帧与插值函数。
- `src/stores/vehicle.ts`：Pinia 车辆开度、目标、播放和中断逻辑。
- `src/scene/v8.ts`：FBX 加载、固定材质、相机、拾取和刚体运动。
- `src/App.vue`：预览界面。
- `scripts/check-v8.mjs`：运行 `node scripts/check-v8.mjs` 检查状态、运动采样、三角玻璃及原文件校验和。

## 运动参数

使用整车 FBX 的父坐标系：厘米，+X 朝车头，+Y 向上，-Z 为车辆左侧。运行场景统一缩放 0.01。左右按车自身方向定义。

`open` 为 0–1；`offset` 是相对关闭位置的厘米位移；`rotationX` 是绕关闭状态玻璃包围盒中心的 X 轴旋转角度。相邻关键帧线性插值，Pinia 开度匀速推进。透明度在加载时设定为常量，动画不改变主玻璃可见性、透明度、顶点形状或裁切平面。

初始轨迹设 0%、25%、50%、75%、100% 五个关键帧，总下降 46 cm、倾角调整 17°，左右镜像。四窗当前均无横向偏移。所有数值是预览调校参数，不是厂家导轨数据。

## 资源与验证边界

原文件直接引用 `model-review/V8 Executive/v8_executive_01/V8-Executive.fbx`。没有修改原模型、减面或转换格式。Vite 构建会复制原 FBX 到 dist。原文件 SHA256：`56df7214c057bcde046b324078721f9e6cde761838a29ec086aed08efd35193c`，与随附作者校验文件相符。

模型来源为 GTV Lab 的 V8 Executive 0.1；随包 README 明确没有骨骼和动画。其分组 pivot 为部件枢轴，不能当作升降导轨。后窗分组同时包含主玻璃与三角玻璃，必须按具体 mesh 映射，而不是整组运动。

前窗几何在前后方向有横向形状变化，统一垂直平移或统一倾角不能自动保证门腔容纳。最初向外偏移的轨迹在半开时露出门皮，已调整；不偏移的全开前窗则有 513 个非去重顶点记录落入对应内饰板包围盒，后半程向外移动 3.3 cm 虽能消除该包围盒重叠，却导致门把手下方玻璃露出门皮，因此未采用，保留无横向偏移的候选轨迹。

测试按每窗 101 个开度验证刚体变换连续、固定三角玻璃不动，并检查状态中断和暂停。当前全开时前窗各有 513 个非去重顶点记录落入对应内饰板包围盒，后窗为 0。内饰板上沿为约 87.5 cm，而全开玻璃上沿约 95 cm，车内方向可能看到玻璃上缘；需补齐工作副本的内侧门腰遮挡几何或进一步校准行程。该包围盒检查不是三角面碰撞证明，也不覆盖所有中间帧、门框、车身及内饰部件。页面是供人工旋转检查的候选轨迹预览，尚未认证全行程无穿插。仍可能需要修改工作副本的门腔/玻璃几何，原件应继续保留。

材质根据 FBX 基础色重建为浏览器 PBR，玻璃固定透明度；并非 Blender 原始节点材质的精确复现。当前为完整高细节模型，手机性能尚未优化。
