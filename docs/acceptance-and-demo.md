## 手机最终验收（建议先iPhone Safari、再Android Chrome）

至少记录实际演示手机；若要宣称同时支持两平台，应各有一台真机结果。访问受信任HTTPS生产预览/正式入口，使用同源API/WSS；局域网启动和证书步骤见 [手机联调](mobile-testing.md)。电脑/手机的机型、浏览器与页面版本不要混用。

| 项目 | 操作与通过标准 |
| --- | --- |
| 入口与加载 | 首次信任证书后无安全警告；允许麦克风；`secureContext=true`；分别记录冷加载/缓存加载，模型完整显示且控件可用。正式服务器验证GLB gzip确实生效，不能照抄本机结果 |
| 旋转与点击 | 持续旋转10秒、松手看阻尼；点击四窗能对应高亮，左右按车辆自身方向；旋转结束不误选车窗 |
| 运动与几何 | 四窗分别检查0/25/50/75/100%，再慢速全程观察左右外侧和车内；主玻璃自然入门、不靠隐藏，三角玻璃不动。运动中反向连续，无瞬移 |
| 底部面板 | 展开/收起始终能看清车窗变化；拖滑块、滚动记录不带动车身；横竖屏切换、地址栏伸缩、文字输入软键盘与底部安全区不挡住必要操作 |
| 真实语音链路 | 用下面演示序列验证原文、目标、高亮、实际动画、记录一致；ASR中间结果不重复执行。实际说话未触发模型时，用文字入口固定输入“右后床开一半”单独确认模型路径 |
| 原子性与记录 | 清空对话后说“开一半，右后窗关上”：整批不动，补“左前窗”后一起执行。“前排半开，右前窗关闭”：整批不动。复合动作运动中手动改右前窗：原记录仅该窗标为替换，其他窗到位后完成 |
| 失效与恢复 | 模型等待时手动操作/取消，晚到结果不得改车窗；续接与pending分别超过60秒后不能沿用旧目标或动作；切后台超过60秒再恢复也检查。拒绝麦克风、静音、断网/恢复后给出提示且可重试，不误执行旧句 |
| 性能与温升 | 用`?perf=1`填机型，均衡/流畅各记录旋转和四窗运动每项10秒，保存平均活跃FPS与帧间隔P95；连续3–5分钟后复测。手机静止时按需渲染停止，FPS=null不算掉帧 |

上下文/失效测试每组先“全部关闭”等到位，再说“取消”，避免前一组影响本组。等模型期间的操作必须发生在结果返回之前；模型过快可用调试端网络节流，不能把动画已开始后的手动覆盖当成晚到响应测试。另测动画已开始后的单窗覆盖，二者分别验收。“取消”清除待执行动作与续接上下文，不是紧急停止已提交的运动。

性能先用低档持续旋转/运动达到约30fps作为建议验收线，均衡以接近60fps为争取目标，需共同确认具体机型标准；目前没有真机数据可以承诺。桌面约175ms场景ready、6.08MB模型压缩载荷不能当作手机加载时长。保存录像和各场景JSON，记录网络、画质、冷/缓存、温热状态；失败项记录输入原文及当时车窗状态。

## 约3分钟成品演示顺序

演示前先检查云端配置、网络、证书与麦克风权限；关闭性能诊断和调试折叠项，选适合设备的画质。点“全部关闭”等到位，再说“取消”清空上下文。从整体视角开始，手机保持面板收起。除专门演示反向/打断外，每句等动画完成再继续；连续对话及补答间隔保持在60秒内，不穿插手动操作。每次录音最多60秒，可按演示段落停止、等最终识别结束后重新开启；对话上下文仍按其自身期限管理。

| 顺序 | 操作/台词 | 展示结果 |
| --- | --- | --- |
| 1 · 旋转（15秒） | 拖动绕车一圈，切左/右侧视角，松手 | 车模、阻尼、四窗与固定三角玻璃；说明左右以车辆自身为准 |
| 2 · 点击（25秒） | 点左前窗选中，点半开；拖滑块打开，中途改为关闭 | 高亮与控件同步，玻璃真实进入门内，反向连续；手机面板操作不带动视角 |
| 3 · 语音（20秒） | 点击麦克风，说“副驾后面的车窗开一半” | 右后窗高亮并到50%，保留识别原文、目标和执行反馈 |
| 4 · 连续对话（25秒） | 等到位，说“再开一点”；到位后说“关上吧” | 同一右后窗50%→60%→0%，其他窗不动；当前开度与目标、完成记录一致 |
| 5 · 连续追问（30秒） | 先说“取消”，再依次说“开一半”→“右车窗”→“右后窗” | 前两句不动，先追问位置再追问前后，最后补齐后执行右后50% |
| 6 · 复合指令（25秒） | 说“能不能帮我把前排开一半、后排关上” | 前排一起到50%，后排一起关闭；最近操作按一句话展示，每窗分别更新状态 |
| 7 · 多窗后续接与收尾（30秒） | 说“再开一点”→被追问后答“左前窗”；等到位，再说“关闭所有车窗” | 不猜多窗后的续接目标；仅左前50%→60%，最后四窗关闭。回看最近操作，展开一条理解详情说明规则/模型来源与耗时 |

可选加演（20秒）：使用文字入口输入“右后床开一半”，展示原文保留、模型理解详情和右后窗50%实际运动。不要故意把“床”读给麦克风并期待ASR一定输出错字；热词可能已正确转写为“窗”。否定句、等待时手动操作、取消与60秒过期归入正式验收，不必全部挤进主线演示。
